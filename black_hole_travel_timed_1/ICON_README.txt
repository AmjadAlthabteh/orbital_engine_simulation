========================================
   HOW TO USE
========================================

STEP 1: Build your project
   - Open Visual Studio
   - Build -> Rebuild Solution
   - Done! Your .exe now has the icon

STEP 2: Switch icons anytime
   - Double-click: choose_icon.bat
   - Select which icon you want
   - Rebuild in Visual Studio

========================================
   TROUBLESHOOTING
========================================

Icon not showing?
 1. Build -> Clean Solution
 2. Build -> Rebuild Solution
 3. Delete old .exe file
 4. Build again

Want to create icons again?
 - Run: generate_icon.bat
 - Choose: 1=BlackHole, 2=Saturn, 3=Both

Change active icon?
 - Run: choose_icon.bat
 - Pick your favorite

========================================
   CUSTOMIZATION
========================================

Want your own icon?
 1. Get/create a .ico file (256x256)
 2. Replace black_hole_icon.ico
 3. Rebuild project

Colors too bright/dark?
 - Edit create_icon.py (line 35-40)
 - Or edit create_saturn_icon.py
 - Change RGB color values
 - Re-run the script
